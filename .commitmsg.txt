有道云笔记命令行工具包

tools/setup.py            下载或定位官方 CLI、修完整性标签、配置 API Key、自检
tools/ynote.py            list / tree / read / search / clip / save-html / delete
tools/ynote_clip.py       HTML 转剪贴板（按 UTF-8 字节计算 CF_HTML 偏移，修掉中文变方块）
tools/ynote_snapshot.py   全库文字快照，输出 md + index.csv + _SUMMARY.txt
docs/workflow.md          接口边界（为什么不能原地改富文本）、HTML 书写约定、坑清单
examples/format-demo.html 格式对照样例
install.bat               双击安装；LICENSE 为 MIT；.gitignore 排除 bin/ 与快照产物

纯 Python 标准库，无第三方依赖，仅支持 Windows。
