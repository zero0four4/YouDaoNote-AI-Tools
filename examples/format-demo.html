格式对照片

把下面每一块贴进有道笔记，看是否和预期一致。
用法：python tools\ynote.py clip --html-file examples\format-demo.html，然后 Ctrl+V。

1. 文字样式

加粗、斜体、下划线、删除线， 普通文字，红色（span style，推荐）， 蓝色， 这段 font 标签是故意写错的，有道不会变红。

2. 表格

步骤命令说明
1python tools\ynote.py list -f 0列根目录
2python tools\ynote.py read <fileId>读正文
3python tools\ynote.py clip --html-file a.html写剪贴板

3. 列表

无序：

  • 第一项
  • 第二项（带 加粗）

有序：

  1. 准备 HTML 片段
  2. 写进剪贴板
  3. 在编辑器里粘贴

4. 代码

行内代码：把片段写到剪贴板用 ynote.py clip。

代码块：

python tools\setup.py
python tools\ynote.py list -f 0
python tools\ynote.py save-html --title "示例" --html-file examples\format-demo.html

5. 引用

读接口只返回纯文本；想让脚本改富文本笔记，只能走「生成 HTML → 你自己粘贴」这条路。

6. 图片

剪贴板里内联的 base64 图片不会上传到图床；需要图片时用：

python tools\ynote.py save-html --title "带图的笔记" --html-file examples\format-demo.html --image 截图.png
